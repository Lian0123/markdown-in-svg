# 視覺審查紀錄

日期：2026-11-02。對象：本包範例及 HTML 閱讀版。使用 Chromium（Playwright headless）實際渲染，再由 AI 檢視截圖。

- SVG 範例：中文正常顯示；付款、確認付款成功後出貨及禁止未付款出貨的規則，與內嵌 Markdown 一致。文字未超出畫布，未見重疊或裁切。兩個流程步驟及箭頭清楚可辨。
- HTML 桌面：1100 px 視窗，首屏標題、文件控制表與狀態文字可讀；頁面量測寬度 1100 px，無橫向溢出。
- HTML 手機：390 px 視窗，首屏文字與表格可讀；全頁量測寬度 390 px，無橫向溢出。

SVG 文字邊界與 HTML 寬度量測見 `render-checks.json`。本紀錄只涵蓋範例及閱讀版的上述檢查，不代表逐頁列印排版檢查、所有條款內容審查、其他字型環境或跨瀏覽器互通性測試。

`verification-report.json` 是自動測試程式的報告，因此其中 visual-review 仍標為 not-checked；本檔另記錄在自動測試之外完成的視覺審查，不將其冒充自動化檢查。
